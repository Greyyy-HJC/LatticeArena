# 2026-11-18 审计与重测记录

这一轮按三个 `tasks/*/todo.md` 做了算子修复、契约冻结和三次 GPU 重测。所有数字都能在

## 1. 算子修复（CPU，已测试）

| task | 问题 | 修复 |
| --- | --- | --- |
| optimize_gaussian | `plaquette` 路径没有闭合（第二/三段沿错方向平移），特征不是规范不变的 | 闭合路径 $U_\mu(x)U_\nu(x+\hat\mu)U_\mu^\dagger(x+\hat\nu)U_\nu^\dagger(x)$ |
| optimize_gaussian | 前向锚点的 plaquette 在翻号旋转下锚点移动，A1+ 不成立 | 改为 **link 中心**平均（每条 link 两侧两个 plaquette） |
| wilson_loop | 逐列 Gram–Schmidt 只保左酉，APE 不满足规范协变 | 双边极分解 $Q=M(M^\dagger M)^{-1/2}$，det→1 |
| wilson_loop | 3 个空间方向只有 4 个 staple，却除以 6 | 改为 $\alpha/4$；新旧 $\alpha$ 关系 $2\alpha/(3-\alpha)$ |
| pion_projection | 参考模型身份靠环境变量，submission 未冻结 | `reference.py` 冻结 kind + 源码 hash；evaluate/candidate 校验 |
| pion_projection | 反射检查硬编码 $T=16$ | 按任意偶数 $T$ 生成 $C(t)-C(T-t)$ |

回归测试：`PYTHONDONTWRITEBYTECODE=1 python -B -m pytest -q -p no:cacheprovider tests/`
（42 项，含全 24 旋转 + parity 的 A1+ 协变、APE 左右协变、缓存/冻结拒绝、合成端到端）。
